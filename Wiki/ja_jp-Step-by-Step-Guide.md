# ステップバイステップガイド

ようこそ！このガイドは初心者の方でも **簡単** に進められるように設計されています。サーバーの運営やModの設定が初めての方でも問題ありません！

---

## 🎮 このModは何ができるの？
通常、Minecraftのサーバーでは全員に強制される1つのリソースパックしか設定できません。

このModを導入すると、**プレイヤーがコマンドを使って自分好みの見た目を自由に選べるようになります！**
例えば、`/pack plastic` と入力してプラスチック風のテクスチャにしたり、`/pack pop` でいつでも元の見た目に戻すことができます。

導入手順はたったの **5ステップ** です！

---

## 📅 ステップ 1: リソースパックのダウンロードURLを用意する
プレイヤーにパックを届けるために、サーバーが `.zip` ファイルをダウンロードできるURLが必要です。

### 方法 A: Modrinth を利用する（一番簡単でおすすめ！）
Modrinthなら直リンクURLを探す手間が不要です！プロジェクトURL、スラッグ、またはバージョンURLをそのまま使えます：
- **プロジェクトURL**: `https://modrinth.com/resourcepack/glass-doors`
- **スラッグ**: `glass-doors`
- **バージョンURL**: `https://modrinth.com/resourcepack/glass-doors/version/1.2.3`

### 方法 B: Discord を利用する
1. リソースパックの `.zip` ファイルをDiscordのチャットにアップロードします。
2. アップロード完了後、ファイルのダウンロード矢印アイコンを **右クリック** します。
3. **「リンクをコピー」** をクリックします。
4. コピーしたURLは `https://cdn.discordapp.com/attachments/.../pack.zip` のようになります（これが直リンクURLです！）。

### 方法 C: Dropbox を利用する
1. `.zip` ファイルをDropboxにアップロードします。
2. **「共有」** ボタンを押してリンクをコピーします。
3. コピーしたリンクは `https://www.dropbox.com/s/.../pack.zip?dl=0` のようになります。
4. リンク末尾の `?dl=0` を `?raw=1` に書き換えます。
5. 完成したURL: `https://www.dropbox.com/s/.../pack.zip?raw=1`（直リンクURL完成！）。

---

## 🔑 ステップ 2: パックの「指紋」コードを取得する（SHA-1ハッシュ）
サーバーはプレイヤーのゲームに *「このパックはもうダウンロード済みだから再ダウンロード不要だよ！」* と伝えるために、40文字のコード（**SHA-1ハッシュ**）を使用します。

### 方法 A: Modrinth の場合（ハッシュ計算不要！）
ステップ1で **方法 A（Modrinth）** を選択した場合、**このステップはスキップできます！** サーバーがModrinthから自動取得してくれます。そのままステップ3へお進みください。

### 方法 B: Webサイトで計算する
1. [https://emn178.github.io/online-tools/sha1_checksum.html](https://emn178.github.io/online-tools/sha1_checksum.html) にアクセスします。
2. リソースパックの `.zip` ファイルを画面の枠内にドラッグ＆ドロップします。
3. 画面上に40桁の英数字（例: `da39a3ee5e6b4b0d3255bfef95601890afd80709`）が表示されます。
4. このコードを **コピー** します！

### 方法 C: Windows PowerShell で計算する（ネット不要）
1. キーボードの **Windowsキー** を押し、**PowerShell** と入力して **Enter** を押します。
2. `Get-FileHash -Algorithm SHA1 ` と入力します（最後に必ず半角スペースを入れてください）。
3. フォルダから `.zip` ファイルをPowerShell画面に直接ドラッグ＆ドロップします。
4. **Enter** を押します。
5. **Hash** 列に表示された40文字のコードをコピーします。

---

## 📝 ステップ 3: 設定ファイルにURLとハッシュを書き込む
Modを導入してサーバーを起動すると、設定ファイルが自動生成されます：

1. Minecraftサーバーのフォルダを開きます。
2. **`config`** フォルダを開きます。
3. **`serverpackswitcher.json`** というファイルを見つけます。
4. ファイルを右クリックし、**「プログラムから開く」** から **「メモ帳」** を選択します。
5. お好みの方法でパックを登録します：

### Modrinth を使う場合:
```json
{
  "packs": {
    "freshanimations": {
      "modrinth": "https://modrinth.com/resourcepack/fresh-animations",
      "required": false,
      "prompt": "Would you like to use the Fresh Animations look?"
    }
  }
}
```
*( `url` や `hash` を書く必要はありません！起動時に自動ダウンロードされます)*

### 直リンクURL（Discord/Dropbox）を使う場合:
```json
{
  "packs": {
    "plastic": {
      "url": "ここにDISCORDまたはDROPBOXの直リンクを貼り付け",
      "hash": "ここに40文字のSHA1コードを貼り付け",
      "required": false,
      "prompt": "Would you like to use the Plastic look?"
    }
  }
}
```

6. ファイルを保存（**Ctrl + S**）してメモ帳を閉じます。

---

## 🔄 ステップ 4: 設定を再読み込みする
すでにサーバーが動いている場合、サーバーを再起動する必要はありません！
1. Minecraftサーバーに参加します。
2. 自分が管理者（`/op` 権限持ち）であることを確認します。
3. **T** または **/** キーを押してチャットを開きます。
4. **`/pack reload`** と入力して **Enter** を押します。
5. 正常にリロードされた旨のメッセージがチャットに表示されます！

---

## 🧱 ステップ 5: ゲーム内でコマンドを使ってみよう

サーバー内の全プレイヤーがチャットで以下のコマンドを使えます：

### 1. 利用可能なパック一覧を見る
入力: **`/pack list`**  
*ステップ3で登録したパック名（"glassdoors" や "plastic" など）が一覧表示されます。*

### 2. 自分にパックを適用する
入力: **`/pack glassdoors`**（または `/pack apply glassdoors`）  
*ダウンロード確認画面が表示されます。**「はい」** をクリック！*

### 3. パックを解除する
入力: **`/pack pop`**（または `/pack clear`）  
*いつでも即座に元のバニラの見た目に戻ります。*

### 4. 管理者コマンド: 他のプレイヤーにパックを適用する
管理者は他のプレイヤーにパックを送信できます：  
入力: **`/pack apply glassdoors Bob`**（Bobを対象プレイヤー名に変更、全員対象なら `@a`）。

---

これで設定は完了です！プレイヤーはいつでも自由にゲームの見た目を切り替えて楽しめます！
