Welcome to the **Server Pack Switcher** Wiki! 

**Server Pack Switcher** is a lightweight, 100% server-side Fabric mod that enables players to choose, download, and apply resource packs using commands. Since it runs completely on the server, players can join with unmodified vanilla clients and still dynamically switch their resource packs.

Use the sidebar navigation on the right to explore the documentation:
- **[[Step-by-Step Guide|Step-by-Step-Guide]]**: A quick, super easy 5-step tutorial on how to set up and use the mod.
- **[[Commands]]**: Learn about commands like `/pack list`, `/pack apply`, and `/pack pop`.
- **[[Configuration]]**: Learn how to configure your resource packs using **Direct URLs** or **Modrinth links**.
- **[[Admin Guide|Admin-Guide]]**: Learn how to manage player preferences, reload configurations, and force packs on players.
