# 명령어 안내

모든 명령어는 기본 접두사 `/pack`으로 시작합니다.

## 명령어 목록

| 명령어 | 권한 요건 | 설명 |
| :--- | :--- | :--- |
| `/pack list` | 누구나 | 구성된 모든 서버 리소스 팩 목록을 확인합니다. |
| `/pack <pack_name>` | 누구나 | 명령어를 입력한 플레이어에게 지정된 리소스 팩을 다운로드하고 적용합니다. |
| `/pack apply <pack_name>` | 누구나 | `/pack <pack_name>` 명령어의 단축 명령어(별칭)입니다. |
| `/pack pop` | 누구나 | 플레이어 클라이언트에 적용된 서버 리소스 팩을 제거합니다. |
| `/pack clear` | 누구나 | `/pack pop` 명령어의 단축 명령어(별칭)입니다. |
| `/pack apply <pack_name> <targets>` | 관리자 (권한 2+) | 대상 플레이어에게 지정된 리소스 팩을 강제로 적용합니다. |
| `/pack pop <targets>` | 관리자 (권한 2+) | 대상 플레이어에게 적용된 서버 리소스 팩을 강제로 제거합니다. |
| `/pack reload` | 관리자 (권한 2+) | 디스크에서 구성 설정 파일을 다시 불러옵니다. |

*참고: 명령어 인자는 TAB 키 자동 완성을 완벽히 지원하여 설정된 팩 이름을 쉽게 입력할 수 있습니다.*

---

## 명령어 세부 정보

### `/pack list`
서버에 설정되어 플레이어가 적용할 수 있는 모든 리소스 팩의 이름을 표시합니다.

### `/pack <pack_name>`
`<pack_name>`과 일치하는 팩을 다운로드하여 게임에 적용합니다. 이미 이 모드를 통해 다른 팩이 적용되어 있는 경우, 충돌 없는 깔끔한 전환을 위해 기존 팩을 먼저 자동으로 제거합니다.

### `/pack pop` / `/pack clear`
현재 적용된 서버 리소스 팩을 클라이언트에서 제거하고 기본 바닐라 상태로 복원합니다.
