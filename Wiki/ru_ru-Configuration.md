# Конфигурация сервера

Мод создает файл конфигурации по пути `config/serverpackswitcher.json` в папке вашего сервера. Вы можете настроить паки с помощью **прямых ссылок (Direct URLs)** или **ссылок Modrinth**.

---

## 🔧 Шаблон JSON
Пример файла конфигурации, демонстрирующий использование как Modrinth, так и прямых ссылок:

```json
{
  "packs": {
    "glassdoors": {
      "modrinth": "https://modrinth.com/resourcepack/glass-doors",
      "required": false,
      "prompt": "Would you like to apply the Glass Doors resource pack?"
    },
    "freshanimations": {
      "modrinth": "https://modrinth.com/resourcepack/fresh-animations",
      "required": false,
      "prompt": "Would you like to apply the Fresh Animations resource pack?"
    },
    "plastic": {
      "url": "https://example.com/plastic_pack.zip",
      "hash": "da39a3ee5e6b4b0d3255bfef95601890afd80709",
      "required": false,
      "prompt": "Would you like to use the Plastic look?"
    }
  }
}
```

---

## 📋 Поля конфигурации
Для каждого ресурса в секции `"packs"` можно указать:

* **`modrinth`** (Необязательная строка): URL проекта на Modrinth (например, `https://modrinth.com/resourcepack/glass-doors`), слаг проекта (например, `glass-doors`) или ссылка на конкретную версию. Если указано, сервер автоматически и асинхронно в фоновом потоке получит прямую ссылку и SHA-1 хеш через Modrinth API при запуске.
* **`url`** (Обязательно, если параметр `modrinth` не указан): Прямая ссылка на скачивание архива `.zip` с ресурс-паком.
* **`hash`** (Необязательная строка): SHA-1 хеш zip-архива (40 шестнадцатеричных символов). Рекомендуется при использовании прямых ссылок для включения кеширования клиентом.
* **`required`** (Необязательный boolean, по умолчанию: `false`): Если `true`, клиенту будет показан обязательный диалог принятия пака.
* **`prompt`** (Необязательная строка): Текст сообщения, отображаемый на экране игрока при запросе на загрузку пака.
* **`id`** (Необязательный UUID): Уникальный идентификатор пака. Если не указан, генерируется автоматически.

## 🔍 Получение прямых ссылок и вычисление хеша (Direct Link)

Если вы не используете Modrinth и хотите настроить прямое скачивание:

### 1. Получение прямой ссылки (Direct URL)
Ссылка должна при переходе сразу инициировать скачивание `.zip` файла без открытия веб-страниц.
- **Discord**: Загрузите архив ресурс-пака в канал, нажмите правой кнопкой мыши по значку скачивания и выберите **Скопировать ссылку**.
- **Dropbox**: Скопируйте ссылку общего доступа и замените `?dl=0` на конце на `?raw=1`.
- **GitHub**: Используйте прямую ссылку на прикрепленный файл релиза (Release Asset).

### 2. Вычисление SHA-1 хеша
Хеш — это уникальный 40-значный отпечаток архива, позволяющий клиенту Minecraft сохранить пак в кеш и не скачивать его повторно:
- **Windows (PowerShell)**:
  ```powershell
  Get-FileHash -Algorithm SHA1 .\my_resource_pack.zip
  ```
- **macOS / Linux (Терминал)**:
  ```bash
  sha1sum my_resource_pack.zip
  ```
- **Онлайн-инструменты**: Перетащите ваш `.zip` в любой онлайн-калькулятор контрольных сумм SHA-1.
