# 관리자 가이드

본 가이드에서는 관리자 기능, 무중단 실시간 설정 리로드 및 플레이어 환경설정 저장 기능을 안내합니다.

---

## 💾 플레이어 설정 영구 저장

플레이어가 `/pack <name>` 명령어로 팩을 선택하면, 서버는 이 선택 사항을 `config/serverpackswitcher_preferences.json`에 자동으로 기록합니다.
- **자동 재적용**: 플레이어가 접속을 종료했다가 나중에 다시 접속하면, 서버는 저장된 환경설정을 자동으로 읽어 해당 팩을 즉시 전송합니다.
- **설정 초기화**: 플레이어가 `/pack pop` 또는 `/pack clear`를 실행하면 설정이 삭제되어 다음 접속 시 어떤 팩도 전송되지 않습니다.

---

## 🔄 무중단 실시간 설정 리로드

서버 실행 도중 `config/serverpackswitcher.json` 파일을 수정했더라도 서버를 재부팅할 필요가 없습니다!
1. 관리자 권한(OP 레벨 2 이상)이 있는지 확인합니다.
2. 게임 내 채팅창이나 서버 콘솔에 **`/pack reload`** 명령어를 입력합니다.
3. 서버가 설정을 즉시 다시 로드합니다. Modrinth 링크를 사용하는 팩은 백그라운드 스레드에서 비동기식으로 다시 확인됩니다.

---

## 🛡️ 대상 지정 관리자 명령어

관리자(권한 레벨 2 이상의 OP)는 다른 플레이어에게 리소스 팩을 강제로 적용하거나 제거할 수 있습니다.

### 리소스 팩 강제 적용
- `/pack apply plastic Bob` - `Bob` 플레이어에게 `plastic` 팩을 강제로 전송합니다.
- `/pack apply plastic @a` - 현재 접속 중인 모든 플레이어에게 `plastic` 팩을 강제로 전송합니다.

### 리소스 팩 강제 제거
- `/pack pop Bob` - `Bob` 플레이어의 적용된 팩을 강제로 제거합니다.
- `/pack pop @a` - 현재 접속 중인 모든 플레이어의 활성 팩을 강제로 제거합니다.
