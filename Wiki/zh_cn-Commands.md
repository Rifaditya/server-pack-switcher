# 指令参考

所有指令均以 `/pack` 基础前缀开头。

## 指令列表

| 指令 | 权限要求 | 说明 |
| :--- | :--- | :--- |
| `/pack list` | 所有人 | 显示所有已配置的服务器资源包列表。 |
| `/pack <pack_name>` | 所有人 | 为执行指令的玩家下载并应用指定的资源包。 |
| `/pack apply <pack_name>` | 所有人 | `/pack <pack_name>` 的别名。 |
| `/pack pop` | 所有人 | 从执行指令的玩家客户端移除当前激活的服务器资源包。 |
| `/pack clear` | 所有人 | `/pack pop` 的别名。 |
| `/pack apply <pack_name> <targets>` | 管理员 (等级 2+) | 强制为指定的目标玩家应用指定的资源包。 |
| `/pack pop <targets>` | 管理员 (等级 2+) | 强制移除指定目标玩家当前激活的服务器资源包。 |
| `/pack reload` | 管理员 (等级 2+) | 从磁盘重新加载配置文件。 |

*注意：指令参数支持对所有已配置资源包名称的自动补全（按 TAB 键提示）。*

---

## 指令详情

### `/pack list`
显示所有已配置且可供玩家应用的资源包名称。

### `/pack <pack_name>`
下载并将与 `<pack_name>` 匹配的资源包应用到您的游戏中。如果您当前已应用了通过本模组加载的其他材质包，模组将自动先将其卸载，以确保干净的替换。

### `/pack pop` / `/pack clear`
从您的客户端清除当前激活的服务器资源包，使游戏恢复为默认外观。
