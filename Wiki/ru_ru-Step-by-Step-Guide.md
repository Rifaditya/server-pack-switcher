# Пошаговое руководство

Добро пожаловать! Это руководство составлено максимально просто и понятно, чтобы каждый администратор мог настроить мод без лишних сложностей.

---

## 🎮 Что делает этот мод?
Обычно сервер Minecraft может отправлять только один общий ресурс-пак, который обязаны загружать все игроки без исключения.

С этим модом **игроки могут сами выбирать внешний вид игры с помощью команд!**
Например, игрок может ввести `/pack plastic` для включения текстур в стиле «пластик» или `/pack pop` для возврата к стандартным текстурам.

Вот как настроить сервер за **5 простых шагов**!

---

## 📅 Шаг 1: Получение ссылки на ресурс-пак
Серверу требуется ссылка, по которой клиенты смогут скачать `.zip` архив ресурс-пака.

### Вариант A: Использование Modrinth (Самый простой и рекомендуемый способ!)
Вам не нужны прямые CDN-ссылки! Достаточно указать ссылку на проект Modrinth, слаг проекта или ссылку на конкретную версию:
- **Ссылка на проект**: `https://modrinth.com/resourcepack/glass-doors`
- **Слаг**: `glass-doors`
- **Ссылка на версию**: `https://modrinth.com/resourcepack/glass-doors/version/1.2.3`

### Вариант B: Через Discord
1. Загрузите `.zip` архив ресурс-пака в любой канал Discord.
2. После загрузки нажмите **правой кнопкой мыши** по стрелке/значку скачивания файла.
3. Выберите пункт **Скопировать ссылку**.
4. Ссылка будет иметь вид: `https://cdn.discordapp.com/attachments/.../pack.zip` (это и есть ваша прямая ссылка!).

### Вариант C: Через Dropbox
1. Загрузите файл `.zip` в Dropbox.
2. Нажмите кнопку **Поделиться** и скопируйте ссылку.
3. Ссылка выглядит так: `https://www.dropbox.com/s/.../pack.zip?dl=0`.
4. Замените окончание ссылки с `?dl=0` на `?raw=1`.
5. Итоговая ссылка: `https://www.dropbox.com/s/.../pack.zip?raw=1` (прямая ссылка готова!).

---

## 🔑 Шаг 2: Получение SHA-1 хеша пака
Сервер передает 40-значный код (называемый **SHA-1 хешем**), чтобы клиент игрока знал: *«Этот пак уже скачан, его не нужно загружать заново!»*

### Вариант A: Через Modrinth (Хеш не требуется!)
Если в Шаге 1 вы выбрали **Вариант A (Modrinth)**, **этот шаг можно пропустить!** Сервер запросит хеш через Modrinth API автоматически. Переходите сразу к Шагу 3.

### Вариант B: Через онлайн-сервис
1. Откройте сайт [https://emn178.github.io/online-tools/sha1_checksum.html](https://emn178.github.io/online-tools/sha1_checksum.html).
2. Перетащите файл архива `.zip` в поле на странице.
3. Сайт мгновенно отобразит 40-значную строку (например: `da39a3ee5e6b4b0d3255bfef95601890afd80709`).
4. **Скопируйте** этот код!

### Вариант C: Через Windows PowerShell (без интернета)
1. Нажмите клавишу **Windows**, введите **PowerShell** и нажмите **Enter**.
2. Введите команду `Get-FileHash -Algorithm SHA1 ` (обязательно с пробелом на конце).
3. Перетащите файл `.zip` из папки в окно PowerShell (путь подставится автоматически).
4. Нажмите **Enter**.
5. Скопируйте строку из колонки **Hash**.

## 📝 Шаг 3: Заполнение конфигурационного файла
После первого запуска сервера с установленным модом создается файл конфигурации:

1. Перейдите в папку сервера Minecraft.
2. Откройте папку **`config`**.
3. Найдите файл **`serverpackswitcher.json`**.
4. Откройте его с помощью любого текстового редактора («Блокнот» и др.).
5. Настройте паки по примерам ниже:

### Пример конфигурации с Modrinth:
```json
{
  "packs": {
    "freshanimations": {
      "modrinth": "https://modrinth.com/resourcepack/fresh-animations",
      "required": false,
      "prompt": "Would you like to use the Fresh Animations look?"
    }
  }
}
```
*(Параметры `url` и `hash` указывать не нужно! Сервер загрузит актуальные данные с Modrinth автоматически).*

### Пример конфигурации с прямой ссылкой:
```json
{
  "packs": {
    "plastic": {
      "url": "ВСТАВЬТЕ_ССЫЛКУ_DISCORD_ИЛИ_DROPBOX",
      "hash": "ВСТАВЬТЕ_40_ЗНАЧНЫЙ_ХЕШ",
      "required": false,
      "prompt": "Would you like to use the Plastic look?"
    }
  }
}
```

6. Сохраните файл (**Ctrl + S**) и закройте текстовый редактор.

## 🔄 Шаг 4: Перезагрузка конфигурации
Если сервер уже запущен, его не нужно перезапускать:
1. Зайдите на свой сервер в Minecraft.
2. Убедитесь, что у вас есть права оператора (`/op`).
3. Откройте игровой чат (клавиша **T** или **/**).
4. Напишите **`/pack reload`** и нажмите **Enter**.
5. В чате появится подтверждение об успешной перезагрузке паков!

---

## 🧱 Шаг 5: Использование команд в игре

Любой игрок на сервере может использовать следующие команды:

### 1. Просмотр списка доступных паков
Команда: **`/pack list`**  
*Показывает названия всех настроенных на Шаге 3 ресурс-паков.*

### 2. Применение ресурс-пака
Команда: **`/pack glassdoors`** (или `/pack apply glassdoors`)  
*На экране появится стандартное окно загрузки ресурс-пака. Нажмите **Да**!*

### 3. Отключение ресурс-пака
Команда: **`/pack pop`** (или `/pack clear`)  
*Игра вернется к стандартным ванильным текстурам.*

### 4. Команда администратора: установка пака другому игроку
Операторы сервера могут применить пак к другому игроку:  
Команда: **`/pack apply glassdoors Bob`** (где Bob — ник игрока, либо `@a` для всех игроков онлайн).
