# 단계별 가이드

환영합니다! 이 가이드는 마인크래프트 서버 운영이나 모드 설정이 처음인 분들도 **쉽게** 따라 할 수 있도록 작성되었습니다.

---

## 🎮 이 모드는 어떤 역할을 하나요?
원래 마인크래프트 서버는 모든 플레이어가 강제로 다운로드해야 하는 하나의 리소스 팩만 적용할 수 있습니다.

하지만 이 모드를 사용하면, **플레이어가 명령어를 입력해 원하는 비주얼을 직접 선택할 수 있습니다!**
예를 들어, 플레이어는 `/pack plastic`을 입력해 블록을 플라스틱 느낌으로 바꾸거나, `/pack pop`을 입력해 언제든지 기본 바닐라 외형으로 돌아갈 수 있습니다.

단 **5단계의 쉬운 과정**으로 설정해 보세요!

---

## 📅 1단계: 리소스 팩 다운로드 링크 준비하기
플레이어에게 리소스 팩을 전송하려면 서버가 `.zip` 파일을 다운로드할 수 있는 경로를 알아야 합니다.

### 방법 A: Modrinth 사용하기 (가장 쉽고 추천하는 방법!)
Modrinth를 이용하면 별도의 직링크나 CDN을 찾을 필요가 없습니다! Modrinth 프로젝트 주소나 슬러그, 버전 주소를 그대로 입력하면 됩니다:
- **프로젝트 URL**: `https://modrinth.com/resourcepack/glass-doors`
- **슬러그**: `glass-doors`
- **버전 URL**: `https://modrinth.com/resourcepack/glass-doors/version/1.2.3`

### 방법 B: 디스코드(Discord) 활용하기
1. 리소스 팩 `.zip` 파일을 디스코드 아무 채널에나 업로드합니다.
2. 업로드가 완료되면 파일의 다운로드 아이콘/화살표를 **우클릭**합니다.
3. **링크 복사**를 클릭합니다.
4. 복사된 링크는 `https://cdn.discordapp.com/attachments/.../pack.zip` 형태가 됩니다 (이것이 직접 다운로드 링크입니다!).

### 방법 C: 드롭박스(Dropbox) 활용하기
1. `.zip` 파일을 Dropbox에 업로드합니다.
2. **공유** 버튼을 누르고 링크를 복사합니다.
3. 링크는 `https://www.dropbox.com/s/.../pack.zip?dl=0` 형태입니다.
4. 주소 맨 끝의 `?dl=0`을 `?raw=1`로 변경합니다.
5. 완성된 주소: `https://www.dropbox.com/s/.../pack.zip?raw=1` (직접 다운로드 주소 완성!).

## 🔑 2단계: 팩의 "디지털 지문" 추출하기 (SHA-1 해시)
서버는 플레이어 컴퓨터에 *«이 팩은 이미 다운로드받았으니 다시 받을 필요 없어!»*라고 알려주기 위해 40자리 코드(**SHA-1 해시**)를 사용합니다.

### 방법 A: Modrinth 이용 시 (해시 추출 불필요!)
1단계에서 **방법 A(Modrinth)**를 선택하셨다면 **이 단계를 건너뛰셔도 됩니다!** 서버가 Modrinth API를 통해 자동으로 해시를 조회합니다. 바로 3단계로 이동하세요.

### 방법 B: 웹사이트 이용하기
1. [https://emn178.github.io/online-tools/sha1_checksum.html](https://emn178.github.io/online-tools/sha1_checksum.html) 에 접속합니다.
2. 리소스 팩 `.zip` 파일을 웹사이트의 상자 안으로 드래그 앤 드롭합니다.
3. 화면에 40자리 문자열(예: `da39a3ee5e6b4b0d3255bfef95601890afd80709`)이 즉시 생성됩니다.
4. 해당 코드를 **복사**합니다!

### 방법 C: Windows PowerShell 이용하기 (오프라인)
1. 키보드의 **Windows 키**를 누르고 **PowerShell**을 입력한 뒤 **Enter**를 누릅니다.
2. `Get-FileHash -Algorithm SHA1 `을 입력합니다 (맨 끝에 공백 한 칸 필수).
3. 폴더에서 리소스 팩 `.zip` 파일을 끌어다 PowerShell 창에 놓습니다.
4. **Enter**를 누릅니다.
5. **Hash** 열 아래에 표시된 40자리 코드를 복사합니다.

## 📝 3단계: 설정 파일에 주소와 해시 입력하기
모드가 설치된 마인크래프트 서버를 처음 실행하면 설정 파일이 생성됩니다:

1. 마인크래프트 서버 폴더로 이동합니다.
2. **`config`** 폴더를 엽니다.
3. **`serverpackswitcher.json`** 파일을 찾습니다.
4. 파일을 마우스 우클릭하고 **연결 프로그램**에서 **메모장**을 선택합니다.
5. 원하는 방식으로 팩을 설정합니다:

### Modrinth 사용 시:
```json
{
  "packs": {
    "freshanimations": {
      "modrinth": "https://modrinth.com/resourcepack/fresh-animations",
      "required": false,
      "prompt": "Would you like to use the Fresh Animations look?"
    }
  }
}
```
*( `url`이나 `hash`를 입력할 필요가 없습니다! 서버가 켤 때 자동으로 최신 정보를 다운로드합니다)*

### 직접 다운로드 링크(Discord/Dropbox) 사용 시:
```json
{
  "packs": {
    "plastic": {
      "url": "여기에_디스코드_또는_드롭박스_링크_붙여넣기",
      "hash": "여기에_40자리_SHA1_해시코드_붙여넣기",
      "required": false,
      "prompt": "Would you like to use the Plastic look?"
    }
  }
}
```

6. 파일을 저장하고(**Ctrl + S**) 메모장을 닫습니다.

## 🔄 4단계: 설정 리로드하기
서버가 이미 실행 중인 경우 서버를 재부팅할 필요가 없습니다:
1. 마인크래프트 서버에 접속합니다.
2. 관리자 권한(`/op`)이 있는지 확인합니다.
3. **T** 또는 **/** 키를 눌러 채팅창을 엽니다.
4. **`/pack reload`**를 입력하고 **Enter**를 누릅니다.
5. 팩이 성공적으로 로드되었다는 메시지가 채팅창에 나타납니다!

## 🧱 5단계: 마인크래프트에서 명령어 사용하기

서버에 있는 모든 플레이어가 게임 내 채팅으로 다음 명령어를 사용할 수 있습니다:

### 1. 사용 가능한 팩 목록 확인
입력: **`/pack list`**  
*3단계에서 등록한 모든 팩의 이름("glassdoors" 또는 "plastic" 등)이 출력됩니다.*

### 2. 자신에게 팩 적용하기
입력: **`/pack glassdoors`** (또는 `/pack apply glassdoors`)  
*팩을 다운로드하고 설치할 것인지 묻는 팝업 화면이 나타납니다. **예(Yes)**를 클릭하세요!*

### 3. 적용된 팩 해제하기
입력: **`/pack pop`** (또는 `/pack clear`)  
*즉시 기본 바닐라 그래픽 상태로 돌아옵니다.*

### 4. 관리자 명령어: 다른 플레이어에게 팩 지정하기
관리자는 다른 플레이어에게 팩을 보낼 수 있습니다:  
입력: **`/pack apply glassdoors Bob`** (Bob 자리에 대상 플레이어 이름을 입력하거나, 모두를 대상으로 할 경우 `@a` 입력).
