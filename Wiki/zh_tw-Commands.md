# 指令參考

所有指令皆以 `/pack` 基礎前綴開頭。

## 指令列表

| 指令 | 權限需求 | 說明 |
| :--- | :--- | :--- |
| `/pack list` | 所有人 | 顯示所有已設定的伺服器資源包列表。 |
| `/pack <pack_name>` | 所有人 | 為執行指令的玩家下載並套用指定的資源包。 |
| `/pack apply <pack_name>` | 所有人 | `/pack <pack_name>` 的別名。 |
| `/pack pop` | 所有人 | 從執行指令的玩家客戶端移除目前啟用的伺服器資源包。 |
| `/pack clear` | 所有人 | `/pack pop` 的別名。 |
| `/pack apply <pack_name> <targets>` | 管理員 (等級 2+) | 強制為指定的目標玩家套用指定的資源包。 |
| `/pack pop <targets>` | 管理員 (等級 2+) | 強制移除指定目標玩家目前啟用的伺服器資源包。 |
| `/pack reload` | 管理員 (等級 2+) | 從磁碟重新載入設定檔案。 |

*注意：指令參數支援對所有已設定資源包名稱的自動補全（按 TAB 鍵提示）。*

---

## 指令詳情

### `/pack list`
顯示所有已設定且可供玩家套用的資源包名稱。

### `/pack <pack_name>`
下載並將與 `<pack_name>` 相符的資源包套用到您的遊戲中。若您目前已套用透過本模組載入的其他材質包，模組將自動先將其卸載，以確保乾淨替換。

### `/pack pop` / `/pack clear`
從您的客戶端清除目前啟用的伺服器資源包，使遊戲恢復為預設外觀。
