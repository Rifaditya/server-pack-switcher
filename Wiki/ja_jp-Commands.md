# コマンドリファレンス

すべてのコマンドは基本プレフィックス `/pack` から始まります。

## コマンド一覧

| コマンド | 必要権限 | 説明 |
| :--- | :--- | :--- |
| `/pack list` | 全員 | 設定されているすべてのサーバーリソースパックの一覧を表示します。 |
| `/pack <pack_name>` | 全員 | 指定したリソースパックを実行したプレイヤーに適用します。 |
| `/pack apply <pack_name>` | 全員 | `/pack <pack_name>` のエイリアス。 |
| `/pack pop` | 全員 | 適用中のサーバーリソースパックをクライアントから解除します。 |
| `/pack clear` | 全員 | `/pack pop` のエイリアス。 |
| `/pack apply <pack_name> <targets>` | 管理者 (レベル 2+) | 対象プレイヤーに指定したリソースパックを強制適用します。 |
| `/pack pop <targets>` | 管理者 (レベル 2+) | 対象プレイヤーのサーバーリソースパックを強制解除します。 |
| `/pack reload` | 管理者 (レベル 2+) | ディスクから設定ファイルを再読み込みします。 |

*注意: コマンドの引数は、設定されているすべてのパック名に対してTABキーによる自動補完に対応しています。*

---

## コマンド詳細

### `/pack list`
プレイヤーが適用可能な、設定済みのすべてのリソースパック名を表示します。

### `/pack <pack_name>`
`<pack_name>` に一致するパックをダウンロードしてゲームに適用します。既にこのModで別のパックが適用されている場合は、安全な切り替えのために自動的に古いパックを解除してから適用されます。

### `/pack pop` / `/pack clear`
適用中のサーバーリソースパックをクライアントから解除し、デフォルトのバニラ状態に戻します。
