# Справочник команд

Все команды мода начинаются с префикса `/pack`.

## Список команд

| Команда | Требуемые права | Описание |
| :--- | :--- | :--- |
| `/pack list` | Доступно всем | Отображает список всех доступных серверных ресурс-паков. |
| `/pack <pack_name>` | Доступно всем | Загружает и применяет указанный ресурс-пак для выполнившего команду игрока. |
| `/pack apply <pack_name>` | Доступно всем | Алиас (синоним) для команды `/pack <pack_name>`. |
| `/pack pop` | Доступно всем | Удаляет активный серверный ресурс-пак у выполнившего команду игрока. |
| `/pack clear` | Доступно всем | Алиас (синоним) для команды `/pack pop`. |
| `/pack apply <pack_name> <targets>` | Администратор (уровень 2+) | Принудительно устанавливает указанный ресурс-пак целевым игрокам. |
| `/pack pop <targets>` | Администратор (уровень 2+) | Принудительно удаляет активный ресурс-пак у указанных целевых игроков. |
| `/pack reload` | Администратор (уровень 2+) | Перезагружает конфигурационный файл с диска без перезапуска сервера. |

*Примечание: аргументы команд поддерживают автодополнение по клавише TAB для всех настроенных имен ресурс-паков.*

---

## Подробности команд

### `/pack list`
Показывает названия всех настроенных на сервере ресурс-паков, доступных игрокам.

### `/pack <pack_name>`
Загружает и применяет ресурс-пак с указанным именем `<pack_name>`. Если у игрока уже был активирован другой серверный пак, мод предварительно удалит старый пак для чистого переключения.

### `/pack pop` / `/pack clear`
Удаляет активный серверный ресурс-пак из клиента игрока, возвращая стандартный внешний вид игры.
